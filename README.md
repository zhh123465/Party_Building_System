## 1. 项目简介

本项目面向高校基层党务助理与支部书记，围绕党员发展“申请人—积极分子—发展对象—预备党员—正式党员—归档”全流程，构建以“规则引擎 + 大模型”双引擎材料核验为核心的轻量化网页系统，实现流程可锁、材料可核、时限可算、风险可见。

系统一期（MVP）目标为跑通：

```text
导入台账 → 上传材料 → 双引擎核验 → 人工复核 → 阶段推进 → 时限预警 → 报表导出
```

## 4. 设计基线（关键决策）

| 决策项 | 结论 |
| --- | --- |
| 交付形态 | 网页端，Chrome / Edge 最近两个大版本，最小分辨率 1366×768 |
| 技术栈 | Java 17 + Spring Boot 3 + MyBatis-Plus + MySQL 8；Vue 3 + Vite + Element Plus + ECharts |
| 数据库 | MySQL 8.0（InnoDB，utf8mb4） |
| 大模型 | OpenAI 兼容 API；POC 使用 tokenrhythm `deepseek-v4.1-flash-1017`，可切换豆包；模型名与提示词版本可配置 |
| 文件存储 | 单机本地非公开目录，经鉴权接口访问，不暴露裸链接 |
| 异步任务 | 数据库任务表 + 应用内调度线程，一期不引入消息队列 |
| 权限模型 | RBAC + 支部数据范围双重校验；一期单主角色 |
| 敏感字段 | 身份证号、手机号 AES-GCM 加密存储，默认掩码，完整值授权查看并留痕 |
| 部署 | 单机 Docker Compose：Nginx + 应用 + MySQL + 文件卷 |

更完整的设计裁决与待确认事项见《需求分析报告》第 9、11 章。

## 8. 重要声明

- 本项目演示与测试一律使用**虚构、脱敏样例数据**。
