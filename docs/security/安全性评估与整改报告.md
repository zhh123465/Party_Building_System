## 2. 已完成的整改

### 2.1 POC 接口鉴权

- `/api/v1/poc/**` 从 `permitAll` 改为必须登录；
- 类级 `@PreAuthorize("hasAnyRole('R1','R2','R3')")`；
- 实测：
  - 未登录：401；
  - 学生 R4：403；
  - 管理员：200。

### 2.2 身份证号完整值

- 查看完整值必须传 `reason`；
- 理由少于 5 字返回 `400 / 20001`；
- 查看成功写入 `VIEW_ID_CARD` 审计日志，包含操作人、IP、理由。

### 2.3 文件上传

- 扩展名 + MIME + **文件头魔数**三重校验；
- PDF 必须以 `%PDF` 开头；
- JPG/PNG 校验文件头；
- DOCX 校验 ZIP 头 `PK\x03\x04`；
- 实测伪装 PDF 返回 `400 / 20002`。

### 2.4 日志与异常

- MyBatis SQL 日志改为 `NoLoggingImpl`，避免 SQL 参数进入日志；
- 参数缺失、类型错误、请求体解析失败统一返回 400；
- 唯一键冲突返回 409；
- 未知异常只返回通用提示与 `traceId`，不返回堆栈。

### 2.5 审计与查看留痕

- 登录、登出、改密；
- 查看材料、下载材料、上传材料；
- 查看完整身份证号；
- 复核、推进、回退、归档；
- 人员导入；
- 报表/归档包导出。

### 2.6 依赖安全

- `npm audit --omit=dev`：**0 vulnerabilities**；
- ECharts 从 5.x 升级到 6.1.0，修复 XSS 公告；
- 前端按需引入 Element Plus，减小包体。

### 2.7 Nginx 加固

- `X-Content-Type-Options: nosniff`；
- `X-Frame-Options: SAMEORIGIN`；
- `Referrer-Policy: strict-origin-when-cross-origin`；
- `Content-Security-Policy`；
- 登录接口限流：每 IP 每分钟 10 次，突发 5 次；
- `server_tokens off`；
- 上传大小限制 25MB。

### 2.8 备份

- 新增 `scripts/backup.sh`：数据库 + 文件目录 + SHA-256；
- 默认保留 28 天；
- 恢复步骤见 `docs/security/备份与恢复说明.md`。

## 4. 正式上线前必须完成

1. **启用 HTTPS**：当前 HTTP 明文，令牌与材料内容可被链路窃听。
2. **更换默认密码**：`admin/Party@2026` 只适用于 POC。
3. **替换 JWT_SECRET / CRYPTO_KEY**：使用 32 字节以上随机值，通过环境变量注入。
4. **限制访问范围**：校园网 IP 白名单、VPN 或 Nginx Basic Auth。
5. **关闭 POC 接口**：正式环境移除 `/api/v1/poc/**`。
6. **配置每日备份 cron**：并完成一次恢复演练。
7. **接入杀毒/沙箱**：至少对上传文件做 ClamAV 扫描。
8. **数据库磁盘加密/访问控制**：仅应用账号可访问，禁止公网暴露。
9. **日志留存与审计导出**：≥6 个月，重要节点前导出留档。
10. **依赖持续扫描**：CI 中执行 `npm audit` 与 Maven 依赖检查。

## 5. 结论

当前系统已完成主要应用层安全整改：

- 接口鉴权与数据范围校验；
- 敏感字段理由与留痕；
- 上传文件类型与内容校验；
- 审计日志；
- 依赖漏洞清零；
- Nginx 安全头与登录限流；
- 备份脚本与恢复说明。

**POC 演示环境可以接受；正式生产环境必须在完成 HTTPS、默认密码、密钥、访问范围、备份演练后上线。**
