# 8 分钟现场演示脚本

> 演示地址：`http://64.83.11.147/`
> 账号：`admin / Party@2026`（R1）、`assistant / Party@2026`（R3）、`student / Party@2026`（R4）
> 全部数据为虚构样例，禁止使用真实政审材料。
> 建议提前打开浏览器标签：工作台、人员台账、流程看板、时限预警、统计报表、电子档案、审计日志。

## 0. 开场（20 秒）

> “党员发展工作目前主要靠 Excel、纸质档案和人工催办。我们做了一个面向基层党务助理的流程智能副驾驶：流程可锁、材料可核、时限可算、风险可见。”

打开工作台，指出人员、阶段、双引擎核验、角色四个卡片。

## 1. 台账导入（50 秒）

1. 进入 **人员台账**；
2. 点击 **批量导入**；
3. 选择 `demo/人员导入样例-20人.xlsx`；
4. 展示导入结果：成功行数、错误行定位（如有）；
5. 强调：学号幂等，重复导入不会产生重复人员。

讲解点：

> “系统替代分散 Excel，形成唯一数据源；错误行会定位到行号和列名。”

## 2. 上传材料与异步核验（50 秒）

1. 打开 **人员台账 → 张明 → 材料**；
2. 在“入党申请书”行点击 **上传**；
3. 选择 `demo/入党申请书-张明.docx`；
4. 展示任务状态：排队中 → 核验中 → 成功；
5. 打开 **查看报告**。

讲解点：

> “上传与核验解耦，30 秒超时自动转人工；文本类 30 秒、扫描件 60 秒的时延基线。”

## 3. 双引擎报告（50 秒）

在报告中指出：

- 规则层：材料是否上传、签名、日期、字数；
- 语义层：入党动机、个人经历、空泛套话；
- 每条结论都有原文依据；
- AI 只给建议，最终由人工复核。

讲解点：

> “规则层保证硬性漏检为 0，模型层负责内容质量；两者分列，避免‘AI 一句话判死刑’。”

## 4. 复核闭环（50 秒）

1. 进入 **材料复核**；
2. 打开一条 M3 材料；
3. 选择“退回整改”，选择原因，填写具体意见；
4. 提交；
5. 切换到学生账号，打开 **消息中心**，展示退回通知；
6. 回到材料页，重新上传 `demo/入党申请书-张明-整改版.docx`，材料回到 M2。

讲解点：

> “退回—整改—重传—通过形成闭环，旧版本保留，退回意见具体到材料。”

## 5. 流程看板与三锁（60 秒）

1. 进入 **流程看板**；
2. 展示人员进度、风险颜色、锁定状态；
3. 选择张明，点击 **推进**；
4. 展示阻塞项：材料未通过、时限逾期等；
5. 选择刘洋（材料齐全），填写会议日期、备案日期、推进依据，勾选确认，推进成功；
6. 展示阶段分布与风险颜色变化。

讲解点：

> “六项规则一次性校验：材料锁、时限锁、流程锁、备案、权限、二次确认；不是逐条试错。”

## 6. 时限预警与倒推排期（50 秒）

1. 进入 **时限预警**；
2. 点击 **生成预警**；
3. 展示逾期/紧迫/临期列表；
4. 处置一条预警；
5. 进入 **发展日历**，选择人员与 2030-06-30，点击 **倒推排期**；
6. 展示各节点最晚完成日与可行性。

讲解点：

> “从‘到期催办’变成‘事前排产’；超过应完成日会阻止阶段推进。”

## 7. 统计报表与合规指数（50 秒）

1. 进入 **统计报表**；
2. 展示阶段人数、完成率、平均合规指数；
3. 展示支部 × 阶段热力图；
4. 点击 **导出 Excel**。

讲解点：

> “合规指数 C=0.40M+0.35T+0.25Q，把三锁变成可排序、可比较的治理指标。”

## 8. 电子档案、检索与审计（50 秒）

1. 人员材料页 → **电子档案**；
2. 展示 S0 阶段 3/3 材料通过；
3. 点击 **归档本阶段**，下载 ZIP；
4. 进入 **档案检索**，输入“入党动机”，展示命中片段；
5. 进入 **审计日志**，展示登录、查看、上传、复核、推进、归档留痕。

讲解点：

> “归档包带清单、SHA-256 与水印；审计日志只增不改不删，敏感字段查看必须填理由。”

## 收尾（20 秒）

> “一期已跑通导入—上传—核验—复核—推进—预警—报表—归档—审计的完整闭环。所有规则、清单、时限、提示词均可配置，下一年改配置不改代码。”

## 演示兜底

| 风险 | 兜底 |
| --- | --- |
| 模型接口慢/失败 | 使用已有报告；说明系统会转人工，不阻断流程 |
| 网络中断 | 提前录屏；本地环境备份 |
| 数据被改乱 | 重新执行演示数据导入；必要时重置数据库 |
| 页面缓存 | `Ctrl + F5` 强制刷新 |
| 时间不够 | 跳过导入、复核，保留看板/预警/报表/审计 |
