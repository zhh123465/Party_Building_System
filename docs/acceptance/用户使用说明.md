# 用户使用说明（POC 版）

> 适用对象：党务助理、支部书记、系统管理员、学生。
> 演示地址：`http://64.83.11.147/`。
> 演示数据均为虚构，禁止上传真实政审材料。

## 1. 登录

使用学号/工号 + 密码登录。

演示账号：

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| `admin` | `Party@2026` | R1 超级管理员 |
| `secretary` | `Party@2026` | R2 支部书记 |
| `assistant` | `Party@2026` | R3 党务助理 |
| `student` | `Party@2026` | R4 学生 |

## 2. 工作台

登录后进入工作台，可查看：

- 人员档案数量；
- 当前阶段范围；
- 双引擎核验状态；
- 快捷入口：流程看板、人员台账、统计报表。

## 3. 人员台账

### 3.1 查询

支持按支部、阶段、姓名/学号筛选。

### 3.2 查看详情

点击“详情”查看人员信息、身份证号掩码。

- R1/R2 可点击“查看完整”；
- 必须填写查看理由（至少 5 字）；
- 查看行为写入审计日志。

### 3.3 批量导入

1. 点击“批量导入”；
2. 选择 Excel；
3. 系统逐行校验，错误行显示行号、列名与原因；
4. 正确行入库，错误行可修正后再次导入；
5. 学号幂等，重复导入不新增重复人员。

样例文件：`demo/人员导入样例-20人.xlsx`。

## 4. 材料核验

### 4.1 上传

人员台账 → 材料 → 上传。

支持 PDF/JPG/PNG/DOCX，单份不超过 20MB。

### 4.2 异步核验

上传成功后：

```text
M2 待核验 → 后台任务 → M3 待人工复核
```

任务失败转 M7，可重试或人工处理。

### 4.3 查看报告

报告分两层：

- 规则层：签名、日期、字数、必填项；
- 语义层：入党动机、个人经历、空泛套话。

每条结论都有规则编号、原文依据、建议。

## 5. 材料复核

- R3 初审：通过后仍为 M3，等待支部书记终审；
- R1/R2 终审：通过后 M4；退回后 M5；
- 退回必须选择原因并填写不少于 10 字的意见；
- 学生会在“消息中心”收到退回通知；
- 重新上传生成新版本，旧版本保留。

## 6. 流程看板

### 6.1 看板

展示人员进度、风险颜色、锁定状态、阻塞项。

### 6.2 推进

1. 点击“推进”；
2. 系统一次性校验六项规则；
3. 有阻塞项时按钮禁用，需先补齐材料/处置预警；
4. 无阻塞时填写会议日期、备案/批复日期、推进依据，勾选确认；
5. 提交后阶段更新，自动生成新阶段材料。

### 6.3 回退

R1/R2 可回退到上一阶段：

- 理由至少 10 字；
- 当前阶段材料置为 M5；
- 写入审计日志。

## 7. 时限预警

- 每日 02:00 自动生成；
- R1 可点击“生成预警”手动触发；
- 级别：提示/临期/紧迫/逾期；
- 可标记“已处理/已忽略”并填写说明；
- 未处置逾期会阻止阶段推进。

## 8. 发展日历

- 选择人员与拟转正日期；
- 点击“倒推排期”；
- 查看各节点最晚开始/完成日、可行性、关键路径；
- 年度日历展示全年预警事项。

## 9. 统计报表

- 阶段人数、完成率、平均合规指数、逾期节点；
- 人员合规指数：M/T/Q 分项、总分、风险；
- 支部 × 阶段热力图；
- 导出 Excel。

## 10. 电子档案

人员材料页 → 电子档案：

- 按阶段查看材料完整性；
- 材料齐全后可“归档本阶段”；
- 生成 ZIP：材料 + `manifest.json` + `watermark.txt`；
- 归档记录可下载。

## 11. 档案检索

输入关键词（如“入党动机”），返回：

- 人员、学号、阶段、材料类型；
- 命中片段；
- 可跳转人员材料页。

## 12. 审计日志（R1）

- 操作日志：登录、查看、上传、复核、推进、回退、归档、导入；
- 导出记录：报表与归档包；
- 支持按账号、操作、对象、时间筛选。

## 13. 移动端使用

- 手机/平板浏览器可直接访问演示地址；
- 左上角汉堡按钮打开导航抽屉；
- 表格可横向滑动；
- 弹窗自适应屏幕宽度；
- 建议横屏查看流程看板与统计报表。

## 14. 常见问题

| 问题 | 处理 |
| --- | --- |
| 登录失败 | 检查账号密码；连续 5 次失败锁定 10 分钟 |
| 上传失败 | 检查格式与大小（≤20MB） |
| 核验一直排队 | 查看后端任务；模型/OCR 可能较慢 |
| 推进被拒 | 查看弹窗阻塞项，先补材料或处置预警 |
| 看不到菜单 | 当前角色无权限，R1/R2/R3/R4 菜单不同 |
| 页面旧版本 | `Ctrl + F5` 强制刷新 |

## 14. 安全提醒

- 演示环境为 HTTP，正式使用必须启用 HTTPS；
- 默认密码仅用于 POC，正式使用必须修改；
- 禁止上传真实政审材料到公网；
- 敏感字段查看会留痕；
- 备份包含个人信息，必须存放在受控目录。
